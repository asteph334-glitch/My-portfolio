# Anne-Marie Stephenson | Marketing portfolio

A premium personal-brand portfolio for a marketing strategist working across brand strategy, SEO, PPC, Meta advertising, digital strategy, integrated campaigns and analytics. Built for membership, education and not-for-profit organisations.

It is one self-contained `index.html` file. There is no build step, no framework and nothing to install.

## Files in this folder

| File | What it is |
|---|---|
| `index.html` | The whole website (design, pages and content) |
| `.nojekyll` | Tells GitHub Pages to serve the file as-is |
| `.gitignore` | Keeps system junk files out of the repository |
| `README.md` | This guide |

## Publish on GitHub Pages

1. Sign in at github.com and click **New repository**.
2. Name it `anne-marie-stephenson-portfolio` (or `YOURUSERNAME.github.io` if you want the shortest address). Leave it **Public** and click **Create repository**.
3. Click **uploading an existing file**, then drag in `index.html`, `README.md`, `.gitignore` and `.nojekyll` from this folder. (If your computer hides files starting with a dot, it is fine to skip `.nojekyll` and `.gitignore`; the site still works.)
4. Click **Commit changes**.
5. Go to **Settings > Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then click **Save**.
6. Wait one to two minutes. Your site appears at `https://YOURUSERNAME.github.io/anne-marie-stephenson-portfolio/` (or `https://YOURUSERNAME.github.io/` for the shortest name).

## Edit your content

Open `index.html` and look for the block that starts with `EDIT YOUR CONTENT HERE`. It holds your email, LinkedIn, About text, case studies, capabilities and audience themes. Anything in `[square brackets]` is a placeholder. Replace it with your real evidence.

To add a case study, copy one block inside `CASES`, give it a new `id` (letters and numbers only, no spaces), and it appears automatically on Home and Work.

On GitHub, open `index.html`, click the pencil icon, edit, then **Commit changes**. The live site updates in a minute or two.

## Important

- Nothing on this site is a real result until you replace the placeholders. Do not publish invented figures.
- The charts on the Evidence page are labelled "sample structure, not real data". Remove that label when you add real numbers.
- Fonts (Bodoni Moda and Instrument Sans) load from Google Fonts, so the site needs an internet connection to show them. Without it, it falls back to Georgia and Arial.
- Check client confidentiality and permission before publishing real names, figures or quotes.
